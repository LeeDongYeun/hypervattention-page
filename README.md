# HyperVAttention Project Page

This repository contains the project page for **HyperVAttention**.

The page is based on the [Nerfies project-page template](https://github.com/nerfies/nerfies.github.io). The adapted website is distributed under the [Creative Commons Attribution-ShareAlike 4.0 International License](https://creativecommons.org/licenses/by-sa/4.0/), following the original template.

## Local preview

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Structure

```text
.
├── index.html
└── static
    ├── css
    ├── images
    ├── js
    └── videos
```

Replace the placeholder copy in `index.html` and add paper assets under `static/images/` and `static/videos/`.
